Embedding Techniques Used

🖼️ JPEG — Steghide

Uses Steghide tool to embed data into the DCT coefficients of JPEG files. Encrypted with AES-128 using a password.
✓ Password protected (AES-128)
✓ Minimal visual change
✓ Detectable by Chi-Square + Extraction
Password: stego123

🖼️ PNG — LSB Substitution

Custom Python implementation that replaces the Least Significant Bit of each pixel channel with one bit of the secret message.
⚠ No encryption (raw bits)
✓ Invisible to naked eye (±1 pixel value)
✓ Extractable without password
Written in Python / NumPy

🎵 WAV — Steghide Audio

Steghide natively supports WAV audio format. Embeds data into audio sample bytes with AES-128 encryption.
✓ Password protected (AES-128)
✓ Inaudible to human ear
✓ Detectable via LSB + Entropy analysis
Password: stego123
Detection Methods Explained

🧪 7 Detection Methods — How Each Works

#MethodHow It Detects SteganographyApplies ToWeight
M1 Chi-Square Attack Tests if adjacent pixel value pairs (0-1, 2-3…) are equally frequent. In natural images they're unequal; in stego images embedding makes them equal. JPEG · PNG 25%
M2 LSB Uniformity Counts how often adjacent pixels flip their LSB. Random messages produce ~50% flip rate; natural images have lower, structured patterns produce higher rates. ALL 20%
M3 Shannon Entropy Measures information content of the LSB plane. Stego images approach maximum entropy (1.0) because embedded bits are pseudo-random. ALL 15%
M4 StegExpose (Java) Password-independent tool using fusion of Primary Sets, RS Analysis, and Sample Pairs. Works without knowing the embedding password. JPEG 10%
M5 Steghide Extraction Actively attempts to extract hidden data using known passwords. If extraction succeeds and returns content, stego is CONFIRMED — most reliable method. JPEG · WAV 50%
M6 LSB Extraction (PNG) Reverses the exact LSB embedding process: reads the first 32 bits as payload length, then extracts that many bytes. No password needed. PNG 100%*
M7 WAV Audio LSB Applies LSB uniformity and Shannon entropy analysis to 16-bit audio sample values. Stego audio shows abnormally random LSB patterns. WAV 30%
* M6 (LSB Extraction) overrides all other scores — if extraction succeeds, verdict is 100% STEGO DETECTED.
