  SECTION 3 — DETECTION METHODS APPLIED
──────────────────────────────────────────────────────────────────────

  [METHOD 1] Chi-Square Statistical Attack
  Principle : Counts pixel value pairs (0-1, 2-3, ...). In natural
              images these are non-uniform. Steghide distributes them
              uniformly, making chi-square value drop toward 0.
  Score     : 0.0 = natural (clean), 1.0 = suspicious (stego)

  [METHOD 2] LSB Uniformity / Run-Length Test
  Principle : Natural images have structured LSB patterns (long runs).
              Stego images replace LSBs with random message bits,
              creating high transition rates (~50% bit flips).
  Score     : 0.0 = structured (clean), 1.0 = random (stego)

  [METHOD 3] Active Steghide Extraction
  Principle : Directly attempts to extract hidden data using password.
              If extraction succeeds, file is CONFIRMED stego.
              This is the definitive method for Steghide-embedded files.
